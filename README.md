# 모바일 청첩장 — 김용현 ♥ 이나연

GitHub Pages용 정적 사이트입니다. 빌드 과정 없이 파일을 그대로 올리면 됩니다.

## 내용 수정
`js/config.js` 한 파일만 고치면 됩니다. `TEMP`가 붙은 값(주소, 전화, 안내 문구, 계좌, 좌표)을 실제 정보로 바꿔 주세요.

## 사진
- 갤러리 사진은 `images/gallery/full/NN.jpg`(크게 보기용, 긴 변 1800px)와 `images/gallery/thumb/NN.jpg`(격자용, 640px) 두 벌로 들어 있습니다.
- 순서를 바꾸거나 사진을 빼려면 `config.js`의 `gallery` 번호 목록만 고치면 됩니다.
- 표지(`cover`)와 맨 아래 감사 인사 배경(`closing`)도 `config.js`에서 바꿉니다.
- 격자에 보이는 썸네일은 **정사각형**이고, 맥 얼굴 인식으로 얼굴이 가운데 오게 잘라 둔 것입니다.
- 사진을 새로 추가할 때(macOS):
  ```bash
  sips -s format jpeg -s formatOptions 80 -Z 1800 원본.JPG --out images/gallery/full/36.jpg
  swift tools/facecrop.swift images/gallery/full images/gallery/thumb 640
  ```
  두 번째 줄은 full 폴더의 모든 사진으로 얼굴 기준 정사각형 썸네일을 다시 만듭니다.

## 배경음악
`audio/bgm.m4a`(Suno로 만든 결혼 초대곡)가 들어 있습니다. 바꾸려면 파일을 교체하고 `config.js`의 `bgm`을 수정합니다.
- 휴대폰 브라우저는 **소리 있는 자동재생을 막습니다.** 그래서 페이지가 열리면 먼저 재생을 시도하고, 막히면 하객이 화면을 처음 터치하는 순간 재생을 시작합니다. 첫 화면에 참석 여부 팝업이 뜨므로 팝업을 누르는 순간 음악이 나옵니다.
- 오른쪽 위 버튼으로 끄고 켤 수 있습니다. 다른 앱으로 넘어가면 일시정지됩니다.
- 파일 크기는 3MB 이하(128kbps, 2~3분 길이)를 권합니다.

## 참석 여부(구글 시트)와 사진 올리기(구글 드라이브) 연결
두 기능 모두 무료 **Google Apps Script** 하나로 처리합니다.

1. 만들어 둔 구글 시트에서 **확장 프로그램 → Apps Script**를 엽니다. 기본 코드를 지우고 `google-apps-script.gs` 내용을 붙여 넣은 뒤 저장합니다. 시트 ID와 드라이브 폴더 ID는 이미 들어 있습니다.
2. 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **실행**을 누른 뒤 권한을 승인합니다. 그러면 시트에 탭 3개가 서식과 함께 만들어집니다.
   - **요약:** 신랑측과 신부측별 응답 수, 참석 인원(동행 포함), 식사 예정·미정·안 함 인원, 불참 수, 사진 장수를 수식으로 자동 집계합니다.
   - **참석여부:** 제출시각, 구분, 참석여부, 성함, 인원, 식사, 연락처, 메시지, 메모 열이 있습니다. 메모 열은 직접 적는 노란 칸입니다. 불참한 줄은 회색으로, 같은 성함이 두 번 이상 나오면 주황색으로 표시됩니다. 필터와 드롭다운도 들어 있습니다.
   - **사진업로드:** 업로드시각, 올린 분, 원본 파일명, 저장 파일명, 드라이브 링크가 기록됩니다.
3. **배포 → 새 배포 → 웹 앱**을 선택합니다. 실행 계정은 **나**, 액세스 권한은 **모든 사용자**로 둡니다.
4. 나오는 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 `config.js`의 `appsScriptUrl`에 넣습니다.
5. **드라이브 폴더 공유를 "제한됨"으로 되돌립니다.** 사진은 스크립트가 나연님 계정으로 저장하므로, 하객에게 폴더 권한이 필요 없습니다. 이렇게 하면 하객끼리 서로의 사진을 보거나 수정, 삭제할 수 없습니다.

결과는 이렇게 쌓입니다.
- 참석 여부는 시트의 `참석여부` 탭에 기록됩니다. 열은 제출시각(KST), 구분, 참석여부, 성함, 인원, 식사, 연락처, 메시지입니다.
- 사진은 드라이브 폴더에 `20270307_143012_홍길동_ab12.jpg` 같은 이름으로 저장되고, 시트의 `사진업로드` 탭에 기록이 남습니다.
- 사진은 휴대폰에서 긴 변 2400px로 줄인 뒤 올라갑니다. 장당 1~2MB 정도이고, 한 번에 30장까지 올릴 수 있습니다.

- 팝업은 처음 들어왔을 때 자동으로 뜹니다. **제출한 사람**이나 **"오늘 하루 보지 않기"**를 누른 사람에게는 다시 뜨지 않습니다(같은 기기 기준). 페이지 중간의 "참석 의사 전달하기" 버튼으로 언제든 다시 열 수 있습니다.
- 팝업이 자동으로 뜨지 않게 하려면 `rsvpPopup: false`로 바꿉니다.
- Apps Script를 수정했다면 **배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.

## 지도 버튼
휴대폰에서는 네이버지도, 카카오맵, 티맵 앱을 바로 엽니다. 앱이 없으면 웹 지도로 넘어가고, 티맵은 앱 스토어로 연결합니다.
`config.js`에 `lat`/`lng` 좌표를 넣으면 장소 검색 대신 길찾기 화면으로 바로 열립니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다(예: `wedding`).
2. 이 폴더의 파일을 전부 올립니다.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/wedding/`에서 열립니다.
5. `index.html`의 `og:image`를 절대 주소로 바꾸면 카톡에 링크를 보낼 때 미리보기 사진이 나옵니다.

## 방명록 (말풍선)
같은 Apps Script와 구글 시트를 씁니다. 글은 시트의 `방명록` 탭에 저장됩니다.
- 하객은 이름, 비밀번호(4자 이상), 메시지(40자, 이모지 가능)를 입력합니다. 비밀번호는 원문이 아니라 해시로만 저장되고, 본인 글을 지울 때 씁니다.
- 지운 글은 줄이 사라지지 않고 '삭제' 칸에 Y가 표시되며 취소선으로 남습니다. Y를 지우면 다시 보입니다.
- 부적절한 글은 시트에서 '삭제' 칸에 Y를 직접 적으면 숨겨집니다.

## 공유 버튼
- **카카오톡으로 공유:** `config.js`의 `kakaoKey`가 비어 있으면 휴대폰 기본 공유창이 열리고, 거기서 카카오톡을 고를 수 있습니다. 카카오 전용 카드(사진, 제목, 버튼)로 보내려면 [Kakao Developers](https://developers.kakao.com)에서 앱을 만듭니다. 그다음 **JavaScript 키**를 `kakaoKey`에 넣고, 플랫폼 → Web에 GitHub Pages 주소를 등록합니다.
- **링크 복사:** 청첩장 주소를 복사합니다.
- **예식 정보 이미지 저장:** 표지 사진, 이름, 일시, 장소, 주소, 교통이 들어간 1080×1920 이미지를 만듭니다. 휴대폰에서는 공유창의 '이미지 저장'으로 앨범에 저장됩니다.

## 사진 피드 (하트·댓글)
갤러리 사진을 누르면 인스타그램처럼 세로로 넘겨 보는 피드가 열립니다.
- **하트:** ♡를 누르거나 사진을 두 번 탭하면 하트가 눌립니다. 같은 기기는 사진당 1개만 셉니다.
- **댓글:** 이름과 댓글(60자)을 남길 수 있습니다. 이름은 다음에 쓸 때 자동으로 채워집니다.
- 하트는 시트의 `사진하트` 탭, 댓글은 `사진댓글` 탭에 쌓입니다. 부적절한 댓글은 '삭제' 칸에 `Y`를 적으면 숨겨집니다.
- 휴대폰의 뒤로가기로 피드를 닫고 갤러리로 돌아옵니다.
